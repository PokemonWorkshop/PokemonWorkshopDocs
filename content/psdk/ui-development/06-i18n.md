Ce guide explique comment localiser les textes d'un plugin via des fichiers CSV et la méthode `ext_text`. L'exemple utilise le plugin Mystery Gift tout au long du guide.

## Principe

Tout texte visible par le joueur doit être stocké dans un fichier CSV. Le système i18n de PSDK sélectionne automatiquement la colonne correspondant à la langue du jeu. Les règles sont strictes :

- Ne jamais écrire de texte en dur dans le code Ruby. Toujours utiliser `ext_text`.
- Chaque fichier CSV porte un identifiant numérique unique (le TEXT_FILE_ID).
- Chaque ligne du CSV correspond à un index (ligne 0 après l'en-tête = ID 0, ligne 1 = ID 1, etc.).
- Les cellules vides utilisent automatiquement la valeur anglaise comme fallback.

## Créer le fichier CSV

Le fichier CSV du plugin Mystery Gift contient tous les textes nécessaires à l'interface. La première ligne est l'en-tête avec les codes de langue, puis chaque ligne suivante est un texte à traduire.

```csv
en,fr,it,de,es,ko,kana
Code,Code,,,,,
Quit,Quitter,,,,,
Mystery Gift,Cadeau Mystère,,,,,
Enter your gift code,Entrez votre code cadeau,,,,,
Invalid code!,Code invalide !,,,,,
Gift already claimed!,Cadeau déjà réclamé !,,,,,
You received %s!,Vous avez reçu %s !,,,,,
No gifts claimed yet,Aucun cadeau réclamé,,,,,
Claim this gift?,Réclamer ce cadeau ?,,,,,
Gift received!,Cadeau reçu !,,,,,
Yes,Oui,,,,,
No,Non,,,,,
```

- La ligne 0 après l'en-tête correspond à l'ID 0 ("Code"), la ligne 1 à l'ID 1 ("Quit"), etc.
- Les colonnes `it`, `de`, `es`, `ko`, `kana` sont vides : le système utilisera automatiquement la valeur anglaise pour ces langues tant qu'elles ne sont pas remplies.
- `%s` dans "You received %s!" est un format specifier Ruby pour les chaînes de caractères. Utiliser `%d` pour les entiers.

## Constantes pour les identifiants de texte

Le fichier CSV porte un identifiant unique (ici 311125). On déclare une constante par ligne du CSV pour éviter les "magic numbers" dans le code.

```ruby
module UI
  module MysteryGift
    # CSV file ID for Mystery Gift i18n text
    TEXT_FILE_ID = 311_125

    # Text row IDs
    TEXT_CODE = 0
    TEXT_QUIT = 1
    TEXT_TITLE = 2
    TEXT_ENTER_CODE = 3
    TEXT_INVALID = 4
    TEXT_ALREADY_CLAIMED = 5
    TEXT_RECEIVED = 6
    TEXT_NO_GIFTS = 7
    TEXT_CLAIM = 8
    TEXT_GIFT_RECEIVED = 9
    TEXT_YES = 10
    TEXT_NO = 11
  end
end
```

- `TEXT_FILE_ID` identifie le fichier CSV dans le système i18n de PSDK.
- Chaque constante `TEXT_*` correspond à un index de ligne dans le CSV. `TEXT_CODE = 0` pointe vers la première ligne de données ("Code").
- Les constantes sont déclarées dans le module `UI::MysteryGift` pour être accessibles par les composants UI et la scène GamePlay via `include`.

## Helper pour accéder au texte

Pour éviter de répéter `ext_text(TEXT_FILE_ID, id)` dans toute la scène, on définit un helper privé dans la classe de scène.

```ruby
module GamePlay
  class MysteryGift < BaseCleanUpdate::FrameBalanced
    include UI::MysteryGift

    private

    # Shortcut to access Mystery Gift text
    # @param id [Integer] the text row index
    # @return [String]
    def gift_text(id)
      return ext_text(TEXT_FILE_ID, id)
    end
  end
end
```

- `include UI::MysteryGift` importe toutes les constantes (`TEXT_FILE_ID`, `TEXT_CODE`, etc.) dans la classe de scène.
- `gift_text(id)` est un raccourci privé. On écrit `gift_text(TEXT_TITLE)` au lieu de `ext_text(311_125, 2)`.
- Le helper retourne directement le texte dans la langue courante du jeu.

## Couleurs de texte

PSDK utilise un système de couleurs indexées, définies dans la palette de la police du jeu.

```ruby
# Indexed colors (from the game's font palette)
add_text(0, 0, 200, 18, gift_text(TEXT_TITLE), color: 0)   # black
add_text(0, 0, 200, 18, gift_text(TEXT_TITLE), color: 1)   # blue
add_text(0, 0, 200, 18, gift_text(TEXT_TITLE), color: 2)   # red
add_text(0, 0, 200, 18, gift_text(TEXT_TITLE), color: 3)   # green
add_text(0, 0, 200, 18, gift_text(TEXT_TITLE), color: 9)   # grey
add_text(0, 0, 200, 18, gift_text(TEXT_TITLE), color: 10)  # white
```

- Le paramètre `color:` accepte un entier correspondant à un index dans la palette de la police.
- Les index les plus courants : 0 (noir), 1 (bleu), 2 (rouge), 3 (vert), 9 (gris), 10 (blanc).

Pour utiliser des couleurs RGB exactes qui ne sont pas dans la palette, on crée le texte sans spécifier `color:` (la valeur par défaut est `nil`), puis on assigne `fill_color` et `outline_color` directement.

```ruby
# Create text without indexed color, then set RGB directly
title = add_text(0, 0, 200, 18, gift_text(TEXT_TITLE))
title.fill_color = Color.new(0, 255, 136)
title.outline_color = Color.new(0, 85, 45)
```

- `color:` est optionnel (défaut `nil`). On peut ne pas le spécifier et assigner les couleurs après.
- `fill_color` définit la couleur de remplissage du texte en RGB.
- `outline_color` définit la couleur du contour. Un pattern courant est de diviser chaque canal par 3 : pour un fill de `(0, 255, 136)`, le outline serait `(0, 85, 45)`.

## Texte dynamique avec format

Quand un texte contient des format specifiers (`%s`, `%d`), la méthode `format` de Ruby remplace les marqueurs par les valeurs fournies.

```ruby
# Display "You received Rare Candy!" or "Vous avez recu Rare Candy !"
gift_name = gift.name
message = format(gift_text(TEXT_RECEIVED), gift_name)
add_text(0, 0, 280, 18, message, color: 1)
```

- `gift_text(TEXT_RECEIVED)` retourne "You received %s!" ou "Vous avez reçu %s !" selon la langue.
- `format(template, gift_name)` remplace `%s` par la valeur de `gift_name`. La méthode `format` de Ruby fonctionne comme `sprintf`.
- Le nom de l'objet (`gift_name`) n'est pas traduit ici car il provient de la base de données du jeu, qui gère sa propre localisation.

## Conclusion

- Tout texte visible par le joueur va dans un fichier CSV avec un identifiant unique (`TEXT_FILE_ID`).
- Utiliser `ext_text(file_id, row_index)` pour accéder au texte dans la langue courante du jeu.
- Définir un helper privé (`gift_text`) dans la scène pour raccourcir les appels à `ext_text`.
- Déclarer des constantes nommées (`TEXT_TITLE`, `TEXT_RECEIVED`, etc.) pour chaque ligne du CSV au lieu d'utiliser des indices numériques.
- Ne jamais écrire de texte en dur dans le code : toujours passer par le CSV et `ext_text`.
- Utiliser `format` avec `%s` ou `%d` pour les textes paramétrés.

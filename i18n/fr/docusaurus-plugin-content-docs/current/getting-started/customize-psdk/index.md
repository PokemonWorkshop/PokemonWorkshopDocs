Des guides pour modifier le comportement de PSDK, du simple ajustement comme le taux de shiny à la personnalisation avancée du moteur. Préparer son environnement et apprendre le monkey-patching.

:::warning[Pas nécessaire pour créer un jeu]
Ces guides s'adressent à celles et ceux qui veulent **personnaliser ou scripter PSDK**, du plus simple (changer le taux de shiny) au plus avancé. Pour simplement créer un jeu avec Pokémon Studio, on peut les ignorer et se rendre directement dans la section **Pokémon Studio**.
:::

## Dans cette section

- [Préparer son environnement de développement](/getting-started/customize-psdk/preparer-son-environnement) : installer Ruby, un éditeur de code et l'autocomplétion PSDK.
- [Monkey-patching](/getting-started/customize-psdk/monkey-patch-dans-psdk) : modifier le comportement de PSDK depuis ses propres scripts sans toucher au code du moteur.
